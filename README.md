# 🚀 Starbase Spotters

Сайт сообщества зрителей запусков Starship. Здесь можно найти место, откуда лучше
всего смотреть старт, почитать отзывы других зрителей и посоревноваться в прогнозах
на тестовые полёты.

## Идея

Вокруг каждого тестового полёта Starship собирается толпа зрителей: кто-то едет на пляж
Бока-Чика, кто-то смотрит с острова Саут-Падре. У всех свои проверенные места и свои
ожидания от полёта. Проект собирает и то, и другое в одном месте.

## Возможности

- **Аккаунты:** регистрация, вход, выход, публичный профиль со статистикой.
- **Точки наблюдения:** пользователи добавляют места с описанием, координатами,
  оценкой обзора, информацией о парковке, связи и количестве людей. Точки видны на карте.
  Изменять и удалять точку может только её автор.
- **Отзывы:** оценка от 1 до 5 и текст. Один отзыв на точку, свою точку оценить нельзя.
- **Полёты и прогнозы:** перед полётом каждый отвечает на три вопроса:
  1. поймает ли башня бустер;
  2. приводнится ли корабль;
  3. во сколько на самом деле будет старт.

  Прогноз можно менять до T-0.
- **Таблица лидеров:** после полёта администратор вносит итоги, очки начисляются
  автоматически: +1 за каждый угаданный исход, +1 за время старта с точностью ±30 минут.

## Быстрый старт

```bash
git clone https://github.com/OWNER/starbase-spotters.git
cd starbase-spotters

python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate

pip install -r requirements-dev.txt
python manage.py migrate
python manage.py seed_demo        # необязательно: демо-данные
python manage.py createsuperuser  # для доступа к /admin/
python manage.py runserver
```

Откройте http://127.0.0.1:8000/.

После `seed_demo` можно войти демо-пользователем `mechazilla_fan`, `boca_local` или
`raptor_counter` с паролем `starship-demo-2026`.

### Переменные окружения

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `DJANGO_SECRET_KEY` | ключ для разработки | секретный ключ, **обязательно** задать в продакшене |
| `DJANGO_DEBUG` | `1` | `0` отключает режим отладки |
| `DJANGO_ALLOWED_HOSTS` | `localhost,127.0.0.1` | разрешённые хосты через запятую |

## Структура проекта

```
├── config/          # настройки, корневые URL, версия приложения
├── core/            # общее: главная страница, миксины, фильтры шаблонов, seed_demo
├── accounts/        # регистрация, вход, профиль
├── spots/           # точки наблюдения и отзывы
├── flights/         # полёты, прогнозы, подсчёт очков
├── templates/       # HTML-шаблоны
├── static/          # CSS и JS (обратный отсчёт, карта)
└── docs/            # документация
```
